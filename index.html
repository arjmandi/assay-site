ASSAY is an LLM reasoning harness. The agent is bound by exactly two things it cannot change: the physics of the world it is connected to, and the physics of its own actions. Everything else the agent works out and writes down itself: what its tools do, what the goal is, and what the world contains. First benchmark: ARC-AGI-3, 24 of 25 games, told only to win.

01

One harness, any world

An agent with these capabilities is different from the LLM it runs on. The same constitution, conditions, budgets, and audit run identically across worlds. ARC-AGI-3 is the first benchmark. Factorio and OOLONG ran their first sweeps under the identical standard.

Physics of the world:

A world arrives as data via a registry and an adapter. Both pieces are fixed. Nothing is assumed in the harness internally the harness understands the world only through these two. The agent is never told what its tools do or what the goal looks like. It discovers both.

Registry
A JSON listing what the agent may do: action names, typed parameters, budgets, gates, the goal. Detail is whatever the world cares to give. Semantics are never included.
Adapter
A Python file with one factory: it returns observations and applies actions. Think of it as MCP for a world.
Physics of action:

The agent cannot act before it commits a machine-checkable prediction of what the action will do. Code grades every prediction against what actually happened. Every action has a price under a hard cap. This makes the agent reason under scarcity. This also makes the agent machine-verifiable and produces a replayable proof of every step. See the full loop.

Once Assay gets connected to a world what it does
Discovers its tools It is not told what its actions do beyond the registry contract. It learns each tool by predicting its effect and paying one action for the answer. The probe share in Fig. 2 is the measured cost of this discovery.
Names what it sees It declares typed channels over the raw observation and stakes its claims on them. (A channel is not silently redefined. New understanding gets a new name, and the journal keeps both.)
Works goals It receives the host’s goal and breaks it into its own subgoals and plans. (It may propose a different goal but it cannot approve its own proposal.)
Learns across runs Knowledge exports between runs. An import enters as a foreign hypothesis and is re-earned through graded claims. New runs do not automatically transfer trust, it must be regained. But graded mechanics and code transfer and prose plans expire.
Stays grounded Every belief comes from a graded prediction, so the agent stays grounded in events happening in real world and will not over-produce actions. Also acting beside the plan cannot be silent because the record shows it. This addresses trusting the agent by design and moves the bottleneck to planning layer.

03

How it works

01 Look
Raw observation arrives from the world adapter.
02 Name
The agent reads the observation through channels, named referents it declared itself. New understanding gets a new name.
03 Predict
A machine-parseable claim about what the action will do, registered before it executes. A bare request to step the world is refused, journaled as ungated, and invalidates the run.
04 Act
A probe spends one action to test one claim. A model that survived grading runs batches through code the agent writes. The batch halts on the first miss.
05 Grade
Code grades every claim against the environment's own response. Out of agent hands. Grades promote or demote trust.
06 Record
Every claim, grade, and action appends to a hash-chained, externally anchored journal.

Note: A broker daemon owns the environment session and its credentials. The agent process never holds them.

Granularities of prediction
Direct state the coarsest form: no-change · change · level-advance · win
Declared channels typed extractors over raw observations, with equality / delta / threshold predicates and bounded temporal windows
Executable verifiers the sharpest form: programs the agent writes, run sandboxed by the referee against the raw before and after observations

We call these the "claim grammar".

The Gaurds
  • Credentials live in the broker and the agent cannot reach the session directly.
  • No action without a pre-registered prediction. Batches halt on first miss. (Unexecuted steps cost nothing.)
  • A claimed world model starts untrusted. Promotion buys only one privilege: longer verified batches and a miss demotes.
  • Goals are pinned by user. The agent can only propose an agenda change. It cannot self-ratify one.
  • The internal paths of processes outside the harness (worlds, benchmark runners, etc) are sealed and are unreadable to the agent.
  • Imported knowledge enters demoted to foreign-hypothesis status. Only graded receipts promote it on the live journal.
Channels: the agent's own referents

A channel is a named reading of the observation, registered once and then claimed against. Goal, level, and remaining budget are built in. The agent declares the rest, as a dotted path into the observation or as a small extractor program that runs in the same sandbox as verifiers. From then on, a rule is checked against a value instead of a memory. A claim that names an unregistered channel is refused before any spend and counted on a mis-reference meter. A channel is never silently redefined. When the lever turns out to be a three-state switch, the agent declares the switch as a new referent and the journal keeps both. This is the answer to referent grounding loss: the referent lives in code, not in the context window.

05

Add new behavioral patterns

Assay allows to pin goals or behavioral patterns that can help in this spicifc world to be entered at start. If in a world you need different search approaches (DFS, BFS, etc) or more general reasoning patterns can be plugged in this way. This feature is not to add world-specific code to the harness but in this architecture that every action is gained via prediction, it's important to treat any agent-side impossibility as a trigger to audit the proof's unexercised rules. “Provably unsolvable” is a property of a model, not a world and if captured a new behavior can be added like a protocol without adjusting the core logic or axioms.

ARC AGI 3: Adding new behaviors to harness

On six occasions the agent proved a level impossible and while every proof was consistent with its recorded transition, all these proofs were of the exact same pattern: they were logically wrong on a decision that no transition had ever traversed. When facing this issue we didn't change the core logic and plugged a new behavior which converted five of the six fails to wins inside their existing action budgets while keeping the harness generality.

Game: DC22L6 · won

“The switch is unreachable, the remaining blocks isolated.”

All 74 inert probes had been taken in a single world-state. One coordinate had been inert earlier and live later, which reframed refuses-to-act as conditional. The gate was geometric arming, and the blocks were connected.

Game: S5I5L7 · won

“Level 7 is provably unwinnable.”

The load-bearing rotation rule had only ever been exercised in the occupied failure mode. One graded probe of the off-board case showed rotation clips rather than refuses. That un-trapped the arm and broke level 8's length cap as well.

Game: SK48L3 · won

“Unsolvable, by exhaustive search over 8.2 million states.”

The search was fully correct given its transition rules. One of them fit all 103 recorded transitions and had never been graded: freed blocks re-hook bottom-only. Re-hooking is positional, and the action written off as a no-op was SELECT.

Game: WA30won

“Throughput ceiling, hostiles effectively unkillable.”

All three hostile rules were false. The kill action works on any adjacent hostile, and the prior session had seven free kills in front of it. Movement is one orthogonal cell per action.

Game: BP35L9 · won

“No switches remain, the map certified pixel-complete.”

Nine switches sat above the map, visible only from inside the “dead-end” shaft. The deepest instance: the unexercised premise was the observation frame itself, with “rendered” standing in for “exists”. Won at 95.27. Running over baseline on late levels costs 0.19 set points.

Game: BP35L8 · won

“The switch is unreachable.”

The switch sat above the drifted map. The map had drifted, not the world. Two of the six proofs broke on this one game.

A new behavior is plugged:

Coverage audit

Step 1
Enumerate the determining rules of the proof.
Step 2
Audit the journal for what actually exercised each rule. Graded evidence in the relevant regime counts. (offline step).
Step 3
Buy graded probes for the gaps (ordered by cost).

07

One harness, Three worlds

Generality is only checkable across domains. The same harness, constitution, and protocol ran unchanged on three worlds, each attached through an adapter and a registry.

World 1 · ARC-AGI-3
The headline benchmark: 24 of 25 games, RHAE 96.54, server-scored on a public scorecard, under hard caps registered before the run. The full evidence pack is above.
World 2 · Factorio
The security test. A published agent, instructed not to cheat, reached the admin channel and spawned resources into its factories. ASSAY closes that class by construction. The registry screens every program the agent proposes and refuses the admin, host, and statistic-forging paths before they execute. On a first calibration sweep of three throughput tasks, the gated agent won all three in 5, 9, and 9 paid actions with zero ungated events.
World 3 · OOLONG
The long-context test. The corpus is written to a file the agent reads with its own offline tools, so the model's context window never holds it. On a first length-ladder sweep at 128K, 1M, and 4M tokens, ASSAY stays in the band of mature general harnesses across the ladder. At 4M it reaches the top of the field, level with Claude Code and ahead of Prime Agent. The bare model cannot answer past 128K.

Protocol · Factorio, open-ended

The calibration sweep establishes the port. The open-ended run is next, where exploit incidents become the direct measurement rather than a design target.

  • Regression gate on a reference game before any new result.
